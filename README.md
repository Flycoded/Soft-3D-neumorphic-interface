# Neumorphic Login & Registration UI

A clean HTML/CSS/vanilla JavaScript recreation inspired by the supplied reference screenshot. This is **original demo source code**, not an extraction of the video's original project.

## Files
- `index.html` - accessible registration and login markup
- `style.css` - soft, raised/pressed (neumorphic) design and responsive layout
- `script.js` - form switching, password show/hide, and front-end validation

## Running
1. Extract the ZIP.
2. Open `index.html` directly in Chrome, Edge, or Firefox.
3. You can also open the folder in Visual Studio Code and use the **Live Server** extension.

## Included
- Create Account and Login views
- Neumorphic circles, input fields, badge, and cyan gradient buttons
- Password visibility toggles
- Required-field, email, password length, and password matching checks
- Responsive on mobile and desktop
- Keyboard focus styles and accessible labels

## Security / integration
**Front-end demo only.** The forms intentionally do not create accounts or log anyone in. There is no database, server, or API, and no credentials are saved or sent. Add a real secure backend (e.g., PHP 8.2 + MySQL) for authentication and registration, using password hashing, server-side validation, HTTPS, CSRF protection, and session security.

Google Fonts will use Poppins when online; system fallback fonts work offline.
